# Faccende di casa

App web per organizzare le faccende tra coinquilini: chi fa una faccenda la segna col suo nome e resta lo storico di chi l'ha fatta e quando; mostra cosa c'è da fare oggi e cosa è in ritardo, e ha un calendario delle prossime quattro settimane.
È fatta in HTML, CSS e JavaScript, senza librerie esterne; per ora è un prototipo e i dati restano nel browser, su un solo dispositivo (localStorage).
Per provarla in locale serve Node.js: esegui `node server.js` e apri http://localhost:5173.
