# Faccende di casa

App web per organizzare le faccende tra coinquilini: assegna i compiti, mostra cosa c'è da fare oggi e cosa è in ritardo, e ha un calendario delle prossime quattro settimane.
È fatta in HTML, CSS e JavaScript, senza librerie esterne; i dati restano nel browser (localStorage).
Per provarla in locale serve Node.js: esegui `node server.js` e apri http://localhost:5173.
